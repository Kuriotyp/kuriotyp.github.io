# Kuriotyp

Felietony technologiczno-kulturowe Marcina Zręda. Strona: https://kuriotyp.github.io

## Struktura

- `_posts/` — felietony w Markdown (`RRRR-MM-DD-slug.md`), pola: `numer`, `title`, `date`, `opis`, `tagi`, `ilustracja`, `zrodlo`
- `ilustracje/` — czarno-białe rysunki ołówkiem do felietonów
- `skille/majeutyka/` — skill Majeutyka (`SKILL.md` + strona)
- `_layouts/`, `_includes/`, `assets/` — wygląd strony

## Nowy felieton

Skopiuj `_templates/felieton.md` do `_posts/`, zmień nazwę na `RRRR-MM-DD-slug.md`, uzupełnij pola i treść.
